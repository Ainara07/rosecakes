
# Rose Cakes — Assignment 6

## Project Description

Rose Cakes is a responsive cake shop website developed
using HTML5, CSS3, Bootstrap 5, JavaScript, and jQuery.

The website allows users to explore cakes, search and
filter products, submit demonstration forms, and manage
their favourite cakes.

## Website Pages

- Home
- Catalog
- About Us
- Order
- Contact
- Register
- My Account
- Demo Result

## Features

- Responsive layout for mobile, tablet, and desktop
- Personalized welcome message using jQuery
- Light and dark theme switcher
- Theme persistence using localStorage
- Animated FAQ using slideUp() and slideDown()
- Ordering Tip using fadeIn() and fadeOut()
- Live cake search and category filtering
- Dynamic Favourite Cakes list
- Favourite Cakes persistence using localStorage
- Contact Form validation using jQuery
- Demonstration registration and order forms
- Keyboard accessibility and focus indicators

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.3
- JavaScript
- jQuery
- localStorage
- GitHub Pages

## Testing

The website includes a testing plan with 15 test cases.

Testing covers:
- Website navigation
- Interactive features
- Search and filters
- Form validation
- Responsive layout
- Keyboard accessibility
- Cross-browser compatibility

Target browsers: Google Chrome and Microsoft Edge.
