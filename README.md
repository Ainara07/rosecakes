
# Rose Cakes — Assignment 5

## Project Description

Rose Cakes is a responsive cake shop website developed
using HTML5, CSS3, Bootstrap 5, and JavaScript.

For Assignment 5, we added a Contact Form and a
Registration Form with validation.

Both forms are demonstrations. No real information
is sent or stored.
